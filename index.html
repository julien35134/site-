Jellyfin, expliqué en français.

Installe ton serveur multimédia, génère ton fichier docker-compose en quelques clics et choisis les bons plugins.

Générer mon docker-compose Lire les guides
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    restart: unless-stopped
    ports:
      - "8096:8096"
    volumes:
      - ./config/jellyfin:/config
      - /mnt/media:/media

Guides pour bien démarrer

Les bases, dans l’ordre où tu en as besoin.

Installer Jellyfin

Le plus simple sur Linux ou NAS : Docker avec le générateur ci-dessous. Sur Windows ou macOS, installe l’application serveur depuis le site officiel. Ouvre ensuite http://IP-du-serveur:8096 et suis l’assistant : compte administrateur, langue, dossiers de médias.

Organiser ses médias

Un dossier par type (films, séries, musique), puis un dossier par titre, par exemple Films/Titre (2020)/Titre (2020).mkv. Respecter les noms recommandés par Jellyfin évite la plupart des erreurs de reconnaissance et d’affiches.

Regarder sur tous ses écrans

Navigateur web, application Android TV, Fire TV, Swiftfin sur iPhone et Apple TV, Findroid sur Android. Le client qui lit directement ton format évite le transcodage, donc moins de charge sur le serveur.

Accès à distance

Le plus sûr est un VPN maillé comme Tailscale : aucun port à ouvrir sur la box. Si tu exposes Jellyfin sur Internet, utilise un reverse proxy avec HTTPS (Caddy, Nginx Proxy Manager), des mots de passe solides et des comptes sans droits d’administrateur. Le guide reverse proxy explique la mise en place.

Sauvegarder

Sauvegarde le dossier de configuration (utilisateurs, métadonnées, historique), pas seulement les médias. Fais une copie avant chaque mise à jour du serveur.

Quel client pour quel appareil ?

Le bon client évite le transcodage et donne une lecture plus fluide. Les disponibilités changent : vérifie sur le magasin d’applications de ton appareil.

Navigateur web

Aucune installation, sur tous les appareils. Pratique pour tester, mais certains formats sont transcodés. Le Chromecast fonctionne depuis le navigateur Chrome.

Android TV et Google TV

Jellyfin pour Android TV Officiel est le meilleur choix sur les téléviseurs et boîtiers Android. Une clé Google TV reste une valeur sûre pour un vieux téléviseur.

Fire TV

Jellyfin Officiel est disponible sur l’Amazon Appstore.

Smartphone et tablette Android

Jellyfin pour Android Officiel, ou Findroid Communautaire qui permet aussi le téléchargement hors ligne. Streamyfin Communautaire existe aussi.

iPhone, iPad et Apple TV

Swiftfin Officiel, gratuit. Infuse Payant est un lecteur très complet qui se connecte à Jellyfin, souvent apprécié pour les formats difficiles.

Samsung et LG

Des applications existent, mais leur installation et leur disponibilité varient selon le modèle et l’année du téléviseur. Si ça pose problème, branche une clé Google TV, un Fire TV ou une Apple TV.

Windows, macOS et Linux

Jellyfin Desktop (anciennement Jellyfin Media Player) Officiel lit presque tous les formats sans transcodage.

Musique

Finamp Communautaire sur mobile, ou Symfonium Payant sur Android, qui gère Jellyfin et Navidrome.

Reverse proxy : Jellyfin en HTTPS

Un reverse proxy reçoit les connexions depuis Internet, gère le certificat HTTPS et les transmet à Jellyfin. Ce guide utilise Caddy : il obtient et renouvelle les certificats tout seul, sur Linux comme sur Windows.

Avant de commencer
  • Il te faut un nom de domaine, ou un sous-domaine gratuit (DuckDNS), qui pointe vers l’adresse IP publique de ta box.
  • Sur la box, redirige les ports 80 et 443 vers la machine qui fait tourner Caddy. Ne redirige pas le port 8096.
  • Si ton opérateur ne te donne pas d’IP publique propre (CGNAT), cette méthode ne marche pas : utilise un VPN comme Tailscale ou un tunnel Cloudflare.

Le fichier de configuration

Le même contenu sert sur Linux et sur Windows. Remplace le nom par ton domaine.

jellyfin.exemple.fr {
    reverse_proxy localhost:8096
}

Si Caddy tourne dans Docker, remplace localhost par le nom du conteneur Jellyfin (par exemple jellyfin) et mets les deux dans le même réseau Docker.

Sur Linux
  • Installe Caddy en suivant la page officielle d’installation (caddyserver.com/docs/install) pour ta distribution.
  • Ouvre le fichier avec sudo nano /etc/caddy/Caddyfile et colle la configuration.
  • Recharge : sudo systemctl reload caddy.
  • Si tu utilises ufw : sudo ufw allow 80,443/tcp.
  • En cas d’erreur : sudo journalctl -u caddy --no-pager | tail -n 30.
Sur Windows
  • Dans PowerShell : winget install CaddyServer.Caddy, ou télécharge Caddy sur caddyserver.com.
  • Crée un dossier, par exemple C:\caddy, avec un fichier nommé Caddyfile (sans extension) contenant la configuration.
  • Ouvre PowerShell dans ce dossier et lance caddy start. Pour le tester au premier plan : caddy run.
  • Ouvre le pare-feu (PowerShell en administrateur) : New-NetFirewallRule -DisplayName "Caddy" -Direction Inbound -Protocol TCP -LocalPort 80,443 -Action Allow.
  • Pour qu’il démarre avec Windows, crée une tâche planifiée « au démarrage » qui lance caddy start. Si le port 80 est déjà pris (IIS, autre serveur), libère-le d’abord.

Côté Jellyfin

  • Dans Tableau de bord, Réseau, laisse « URL de base » vide.
  • Ajoute l’adresse du proxy dans « Proxys connus » (127.0.0.1 si Caddy est sur la même machine) pour que Jellyfin voie les vraies adresses des visiteurs.
  • Teste en ouvrant https://jellyfin.exemple.fr depuis la 4G, pas depuis ton Wi-Fi.
Sécurité
  • N’expose que les ports 80 et 443, jamais Sonarr, Radarr ou les autres services.
  • Mots de passe solides, et comptes sans droits d’administrateur pour les proches.
  • Garde Jellyfin et Caddy à jour.
  • Tu préfères une interface graphique ? Nginx Proxy Manager, sous Docker, propose des boutons pour les certificats.

Plugins : lesquels installer ?


Le catalogue se trouve dans Tableau de bord, Plugins. Redémarre le serveur après chaque installation.


Mes conseils

  • Commence avec peu de plugins : chacun tourne avec les droits du serveur, donc ne mets que ceux dont tu as besoin.
    • 

  • Préfère le catalogue officiel. Les plugins communautaires demandent d’ajouter un dépôt : vérifie la date de dernière mise à jour et les avis.
    • 

  • Un plugin dépend de la version du serveur. Avant de mettre Jellyfin à jour, sauvegarde, puis vérifie la compatibilité.




Open Subtitles Officiel
Télécharge automatiquement les sous-titres manquants, y compris en français. Il faut un compte gratuit sur le service.


Playback Reporting Officiel
Statistiques de lecture : qui regarde quoi, et quand. Pratique pour savoir ce qui sert vraiment.


TMDb Box Sets Officiel
Regroupe les films d’une même saga dans une collection.


Trakt Officiel
Synchronise ton historique de visionnage avec ton compte Trakt.


Intro Skipper Communautaire
Détecte les génériques de début et ajoute un bouton « passer l’intro ». Vient d’un dépôt tiers : lis sa documentation avant d’installer.


Thèmes CSS Communautaire
Ce n’est pas un plugin : colle un thème (ElegantFin, Ultrachromic) dans Tableau de bord, Général, CSS personnalisé, pour changer l’apparence.





Questions fréquentes


Je n’ai pas de son, ou le son est décalé
Souvent un codec audio que le client ne sait pas lire (DTS, TrueHD). Jellyfin le transcode alors, ce qui demande de la puissance. Essaie un autre client, ou choisis une piste audio compatible (AAC, AC3).


La lecture saccade ou charge sans fin
Regarde dans le tableau de bord si la lecture est transcodée. Si oui, baisse la qualité, change de client ou active l’accélération matérielle. Vérifie aussi le débit du Wi-Fi.


Les sous-titres ne s’affichent pas
Les sous-titres image (PGS) forcent souvent le transcodage. Préfère le format SRT ou ASS, ou installe le plugin Open Subtitles.


Une affiche ou un titre est faux
Vérifie le nom du dossier et du fichier, puis utilise « Identifier » sur la fiche du média pour choisir le bon résultat.


Comment mettre Jellyfin à jour avec Docker ?
Sauvegarde ta configuration, puis lance docker compose pull et docker compose up -d.
